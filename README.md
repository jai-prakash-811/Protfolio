# Jai Prakash Thakur — Portfolio

A personal portfolio website showcasing my skills, projects, and resume.

🔗 **Live Demo:** _add your deployed link here (e.g. Vercel/Netlify)_

## Built With
- HTML5, CSS3, JavaScript (vanilla)
- [Typed.js](https://github.com/mattboldt/typed.js/) — animated hero text
- [ScrollReveal](https://scrollrevealjs.org/) — scroll animations
- [Boxicons](https://boxicons.com/) — icons

## Features
- Responsive layout with a mobile hamburger menu
- Animated typing effect and scroll-reveal transitions
- Skills section with progress bars
- Projects section with 3D tilt hover effect
- Contact form (powered by [FormSubmit](https://formsubmit.co/) — no backend needed)
- Downloadable resume/CV

## Getting Started
1. Clone this repository
2. Open `index.html` in your browser — no build step required
3. In `index.html`, replace `YOUR_EMAIL@example.com` in the contact form's `action` attribute with your real email address (FormSubmit will send an activation email the first time)
